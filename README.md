# LAW Electrics — website demo

A responsive one-page website concept for LAW Electrics, a domestic and commercial electrician serving Greater Manchester.

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:4178`.

## Test

```bash
npx playwright install chromium
npm test
```

The Playwright checks cover the 390px, 768px and 1440px layouts, core navigation, the mobile menu, the interactive job selector, links, browser errors and horizontal overflow.

## Content sources

Business details and claims are based on the supplied Instagram profile screenshots and LAW Electrics' public Nextdoor business page. The project imagery is presented from the supplied Instagram screenshot and is not synthetic stock imagery.
